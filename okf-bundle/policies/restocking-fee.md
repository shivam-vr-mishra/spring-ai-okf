# Restocking Fee

> **DEPRECATED — withdrawn 1 January 2026.** Retained for audit history only.
> This file is a trap for the demo: it is lexically very close to a returns
> question and vector search ranks it highly, but acting on it would give the

A restocking fee of 15% of the purchase price is deducted from the refund on
all returned items, including items returned because they arrived damaged or
broken. The customer pays return shipping in all cases with no exceptions.
